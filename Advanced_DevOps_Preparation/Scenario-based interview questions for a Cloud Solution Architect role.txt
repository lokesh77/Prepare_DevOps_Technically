Scenario-based interview questions for a Cloud Solution Architect role:

---

### 1. A customer wants to migrate a legacy 3-tier on-prem application to Azure but can’t afford downtime. What architecture and migration strategy would you recommend?

**Answer:**
- **Architecture:** Use Azure App Service for the frontend, AKS (Azure Kubernetes Service) for the application layer, and Azure SQL Database with geo-replication for the backend.
- **Migration Strategy:**
  1. Set up a staging environment in Azure.
  2. Use Azure Database Migration Service for live data replication.
  3. Implement Azure Traffic Manager for blue-green deployments.
  4. Perform a final cutover during off-peak hours, ensuring minimal downtime.

---

### 2. You’re tasked with designing a secure cloud-based platform for a healthcare provider. How would you ensure HIPAA compliance across all services?

**Answer:**
- Use **Azure Security Center** to monitor and enforce compliance.
- Encrypt data at rest (Azure Storage) and in transit (TLS 1.2).
- Store sensitive data in **Azure Key Vault**.
- Implement **RBAC (Role-Based Access Control)** to restrict access.
- Enable **Azure Policy** for enforcing HIPAA compliance policies.

---

### 3. An enterprise client experiences latency issues in India and Australia using AWS. How would you redesign the architecture to improve global performance?

**Answer:**
- Use **AWS Global Accelerator** for directing traffic to the nearest edge location.
- Deploy the application in multiple AWS regions (e.g., Mumbai and Sydney).
- Use **Amazon CloudFront** as a CDN for caching static assets.
- Configure **Route 53 latency-based routing** for optimal region selection.

---

### 4. A retail company has unpredictable traffic surges during sales. How would you build a cost-effective, auto-scalable infrastructure for their e-commerce application?

**Answer:**
- Use **AWS Auto Scaling** for EC2 instances.
- Deploy a serverless architecture with **AWS Lambda** for specific tasks.
- Use **Amazon RDS** with read replicas for the database layer.
- Store static assets in **Amazon S3** with **CloudFront** for delivery.

---

### 5. You notice a massive spike in cloud spend for a project that just went live. What steps would you take to identify and resolve the issue?

**Answer:**
1. Analyze billing data using **AWS Cost Explorer** or **Azure Cost Management**.
2. Check for unused or over-provisioned resources.
3. Use **tags** to map costs to specific teams or resources.
4. Optimize resources (e.g., use Spot Instances, right-size VMs).
5. Set **alerts** for unusual spending patterns.

---

### 6. The development team wants to push 50+ microservices to production weekly. How would you ensure reliability, traceability, and security in the deployment process?

**Answer:**
- Use CI/CD pipelines with tools like **Jenkins** or **Azure DevOps**.
- Implement **Canary Deployments** for gradual rollouts.
- Use a **service mesh** like Istio for managing communication between microservices.
- Enable distributed tracing with **AWS X-Ray** or **Azure Monitor Application Insights**.

---

### 7. How would you architect a real-time analytics platform that ingests terabytes of IoT sensor data from thousands of devices worldwide?

**Answer:**
- Use **Azure IoT Hub** or **AWS IoT Core** for ingestion.
- Process data in real-time with **Azure Stream Analytics** or **AWS Kinesis**.
- Store raw data in **Azure Data Lake** or **Amazon S3**.
- Perform analytics using **Azure Synapse Analytics** or **AWS Redshift**.

---

### 8. A government project requires on-prem data residency but wants the agility of cloud compute. How would you design a hybrid solution?

**Answer:**
- Use **Azure Stack Hub** or **AWS Outposts** to extend cloud services to on-prem.
- Establish secure connectivity using **Azure ExpressRoute** or **AWS Direct Connect**.
- Synchronize data across environments with **hybrid identity solutions** like Azure AD.

---

### 9. You inherit a complex cloud environment with poor documentation and inconsistent naming conventions. How would you standardize and govern it?

**Answer:**
- Conduct a full **audit** of cloud resources and policies.
- Define and enforce a **naming convention** (e.g., resource-type-region-env).
- Use **Infrastructure as Code (IaC)** with Terraform for consistent deployments.
- Enable **Azure Policy** or **AWS Config** for governance.

---

### 10. A company needs to securely connect its on-prem Active Directory with Azure AD. Walk me through your integration approach.

**Answer:**
- Use **Azure AD Connect** for synchronization.
- Enable **password hash synchronization** or **pass-through authentication**.
- Set up **Conditional Access Policies** for secure access.
- Implement **Seamless SSO** for unified user experience.

---

### 11. You’re designing a multi-cloud architecture for financial workloads. How do you ensure failover and data integrity across AWS and Azure?

**Answer:**
- Use **cross-cloud data replication** (e.g., SQL Server Always On).
- Implement DNS-based failover with **Route 53** and **Azure Traffic Manager**.
- Use **Kubernetes** for orchestration across clouds.

---

### 12. An application stores sensitive PII data and is being accessed by third-party services. How would you ensure secure access and auditability?

**Answer:**
- Use OAuth 2.0 or an API Gateway for secure access.
- Encrypt data at rest (e.g., **AWS KMS**, **Azure Key Vault**).
- Enable logging with **AWS CloudTrail** or **Azure Monitor** for auditability.

---

### 13. An e-commerce platform is experiencing downtime due to a single point of failure in their database. How would you redesign this for high availability?

**Answer:**
- Use **multi-AZ deployment** for the database.
- Implement **read replicas** to handle read traffic.
- Use **Amazon Aurora** or **Azure SQL with Failover Groups** for automatic failover.

---

### 14. You’re building a cloud-native ML inference system with real-time scoring. How do you architect for scalability and low-latency inference?

**Answer:**
- Deploy the model on **AWS SageMaker Endpoints** or **Azure Machine Learning**.
- Use **GPU-optimized instances** (e.g., AWS G5, Azure NC-Series).
- Scale inference requests with **Elastic Load Balancers**.

---

### 15. You’re tasked with implementing centralized logging, monitoring, and alerting for 100+ services across multiple subscriptions. What's your solution?

**Answer:**
- Use **Azure Monitor** with Log Analytics for centralized logging.
- Implement **AWS CloudWatch** dashboards.
- Use **ELK Stack** (Elasticsearch, Logstash, Kibana) for multi-account logging.

---

### 16. Your client is worried about vendor lock-in. How do you design a cloud architecture that minimizes reliance on proprietary services?

**Answer:**
- Use **open-source tools** (e.g., Kubernetes, Terraform).
- Store data in **cloud-agnostic formats** (e.g., Parquet).
- Implement a **multi-cloud strategy** with consistent tooling.

---

### 17. An app in production is receiving timeout errors intermittently. The cloud health dashboard shows no issues. How do you investigate and resolve it?

**Answer:**
- Check **application logs** for bottlenecks.
- Use **distributed tracing** to identify latency sources.
- Analyze **network latency** with tools like traceroute or Ping.

---

### 18. Your application has multiple teams working in parallel. How do you architect cloud environments to enable secure, isolated Dev/Test/Prod pipelines?

**Answer:**
- Use **separate subscriptions/accounts** for each environment.
- Implement **RBAC** for access control.
- Automate environment creation with **IaC** (Terraform, CloudFormation).

---

### 19. How would you approach deploying an internal LLM model on a GPU-optimized Kubernetes cluster in the cloud?

**Answer:**
- Use a **GPU-optimized Kubernetes cluster** (e.g., EKS with G4 instances).
- Deploy the model using **Kubeflow**.
- Scale inference with **Horizontal Pod Autoscaler (HPA)**.

---

### 20. A fintech app requires sub-second latency for trades but needs regional compliance for user data. How do you balance both requirements?

**Answer:**
- Use **AWS Local Zones** or **Azure Edge Zones** for low-latency compute.
- Implement **regional data residency** with multi-region databases.
- Use **low-latency messaging systems** like Kafka.
