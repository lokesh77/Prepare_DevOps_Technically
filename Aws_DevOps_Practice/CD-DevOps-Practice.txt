14. **How do you dynamically retrieve VPC details from AWS to create an EC2 instance using IaC?**
    **Answer:** Use the `data` block in Terraform to fetch existing VPC details.  
    **Example:**  
    ```hcl
    data "aws_vpc" "selected" {
      filter {
        name   = "tag:Name"
        values = ["my-vpc"]
      }
    }
    ```

15. **How do you manage unmanaged AWS resources in Terraform?**
    **Answer:** Use the `terraform import` command to bring existing resources under Terraform management.  
    **Example:**  
    ```bash
    terraform import aws_instance.my_instance i-0abcd1234efgh5678
    ```

16. **How do you pass arguments to a VPC while using the `terraform import` command?**
    **Answer:** Provide the resource identifier as an argument.  
    **Example:**  
    ```bash
    terraform import aws_vpc.my_vpc vpc-123abc45
    ```

34. **Explain the blue-green deployment, canary deployment, and rollback processes with real-time scenarios.**  
   **Answer:**  
   - **Blue-Green Deployment:** Deploy the new version (green) alongside the current version (blue) and switch traffic to the green environment after validation.  
     **Example:** Used AWS CodeDeploy to implement blue-green deployment for a microservices architecture, ensuring zero downtime.  
   - **Canary Deployment:** Gradually roll out a new version to a subset of users and monitor its performance before full rollout.  
     **Example:** Launched a new feature in a SaaS application to 10% of users using Kubernetes annotations for canary deployment.  
   - **Rollback:** Revert to a previous stable version if issues occur.  
     **Example:** Rolled back a failed deployment in Kubernetes using `kubectl rollout undo` to restore the stable version.

35. **What are the advantages and disadvantages of using feature flags in CI/CD?**  
   **Answer:**  
   - **Advantages:**  
     - Enable safe deployment of incomplete features.  
     - Allow A/B testing and controlled rollouts.  
     - Simplify rollback by disabling the flag instead of redeploying the application.  
   - **Disadvantages:**  
     - Introduce complexity in code and configuration management.  
     - Require proper cleanup to avoid tech debt.  
   **Real-World Example:** Used feature flags in LaunchDarkly to enable a new billing module for a subset of users in a production environment.
