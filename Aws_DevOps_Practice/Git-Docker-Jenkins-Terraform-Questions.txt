1. **What is GIT stash?**  
   **Answer:** `git stash` temporarily saves uncommitted changes in the working directory so you can switch branches or perform other tasks without losing your progress.  
   **Real-World Example:** While working on a feature, you can stash your changes to quickly switch to a different branch for an urgent bug fix.  
   **Command Example:**  
   ```bash
   git stash
   git stash apply
   ```

2. **What is a branching strategy?**  
   **Answer:** A branching strategy defines how branches are created and managed in a version control system.  
   - **GitFlow:** Separate branches for features, releases, and hotfixes.  
   - **GitHub Flow:** Single main branch with feature branches.  
   - **Trunk-Based Development:** All changes are committed to the main branch.  
   **Real-World Example:** A team uses GitFlow to manage feature development and bug fixes in parallel.

3. **What is the command to discard changes in the working directory?**  
   **Answer:**  
   ```bash
   git checkout -- <file>
   ```  
   or  
   ```bash
   git reset --hard
   ```

4. **How do you debug the exited container?**  
   **Answer:** Use the following command to inspect logs and the state of the container:  
   ```bash
   docker logs <container-id>
   docker inspect <container-id>
   ```

5. **How do you execute jobs in parallel in Jenkins?**  
   **Answer:**  
   - Use the `parallel` step in declarative pipelines.  
   **Pipeline Example:**  
   ```groovy
   parallel {
       stage('Job 1') {
           steps {
               echo "Executing Job 1"
           }
       }
       stage('Job 2') {
           steps {
               echo "Executing Job 2"
           }
       }
   }
   ```

6. **Maven Lifecycle?**  
   **Answer:**  
   - **Phases:** Validate, Compile, Test, Package, Verify, Install, Deploy.  
   - Each phase builds upon the previous one.  
   **Real-World Example:** The `mvn package` command compiles and runs tests before packaging the application.

7. **How do you upgrade Jenkins?**  
   **Answer:**  
   - Backup Jenkins configurations.  
   - Download the latest `.war` file.  
   - Replace the existing Jenkins `.war` file and restart the server.  

8. **What is a Parameterized Job in Jenkins?**  
   **Answer:** A job that accepts user-defined parameters at runtime, such as environment variables or file paths.  
   **Real-World Example:** A Jenkins job takes an environment (dev, test, prod) as input to deploy an application.
